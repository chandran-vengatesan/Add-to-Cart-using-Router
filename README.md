
# Add-to-Cart using Router

A React application demonstrating shopping cart functionality with React Router for navigation.

## Features

- Product listing display
- Add/remove items from cart
- Cart management with React Router
- Responsive design

## Tech Stack

- React
- React Router
- JavaScript
- CSS

## Installation

```bash
npm install
npm start
```

## Usage

1. Browse products on the home page
2. Click "Add to Cart" to add items
3. Navigate to cart to view selected items
4. Manage quantities and remove items as needed
